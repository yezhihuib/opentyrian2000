# NEWSHI bank13 native runtime validation

`large_newshi_native_validation.py` compiles the default-off, HD-on and mirror-disabled configurations and runs a controlled ASan/UBSan harness linked with production allocation and sprite blitters. Private original bank/records enter stdin only. This is not natural gameplay or Windows evidence.

The finite profiles cover records302–308, seven normal poses and all ten damaged nose cycle positions3–12. The normal-to-damaged state block is copied unchanged from `tyrian2.c` and its exact source substring is checked before compilation. Triggering that block is controlled; it does not establish natural collision timing. Cycle2 is accepted only as the narrowly specified post-draw state, never as a drawn resource.

The matrix also retains all old18-resource draw oracles, separate bank13-only eligibility, independent record/bank/palette/resource/slot leases, mixed-bank final/cache dependencies after ownership erasure, split links/missing parts, clipping, optional-group malformed resources, unknown-foreign soft-edge fallback and all28 resource-pointer retirement. Actual E1L12 captures and typed ShapesY borrowing diagnostics are separate required evidence.

Receipts are qualified only when status, source_unchanged and test_unchanged are all true. Intermediate logs created during implementation are not qualification.

Typed ShapesY borrowing is positive-scene evidence at density8 only, preserving the existing ShapesY gate. Density4 still exercises NEWSHI drawing and strict unknown-foreign actor-local fallback; it does not claim a typed ShapesY lease. The soft preflight and synthetic mask oracle both zero-initialize sparse decoder output, so transparent cells cannot acquire indeterminate coverage.

The strengthened controlled tests additionally bind the native animation increment/wrap and firing gate text exactly, assert original weapon151/frequency8 and unchanged shot countdown, and compare RNG fingerprints around each quartet. They do not run or replace the firing loop.

Zero-initialization regression: all44 quadrants from old dual phase15 plus new phases18–27 are decoded into both zeroed and `0xa5`-poisoned buffers. Native assertions prove uncovered index/coverage bytes remain zero only in the initialized buffer and remain poison in the sparse-decoder control. The driver enforces the production preflight's zero initializer and deterministically rejects the exact former uninitialized declaration. This source-bound guard plus native transparent-mask assertions is not a stack-luck mutation test.
