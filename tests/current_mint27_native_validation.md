# Current Mint27 native validation

The finite adapter SHA-pins the historical full-production native driver. It validates current Mint27 derivation, adds its one current HDA and isolated malformed fixtures, and links an explicit new C harness against the production renderer, indexed blitters, entity wrapper and native objects. The legacy P09/P05 matrix remains unchanged.

Run `tests/current_mint27_native_validation.py` using the same `--original-data`, `--sysroot`, `--base-build`, `--assets`, `--out`, and `--current-sonic-art` arguments as the historical driver. `--source-root` selects an isolated bootstrap or genuinely stage/applied edited source root. The asset directory must contain the existing P02/P04/P05/P09 family files; Mint27 is independently loaded from its validated canonical derivation.

The additions check the existing player-shot generic wrapper at two slot values, the dedicated Mint27 shadow, per-pixel ordinary and shadow alpha, indexed pixels, RNG and player-shot state preservation, existing source hash and identity/slot/geometry, malformed/missing resource fallback, same-address source reload, payload corruption rejection for the shadow lease, later indexed ownership, and fade invalidation. The shadow oracle preserves the existing full-strength rounded shadow followed by alpha blending; it is not the generic Guided shadow's single-rounding formula.

These are controlled native wrapper calls. The test does not establish native Mint27 weapon creation, native sidekick firing attribution, sidekick body rendering, natural campaign appearance, Windows execution or physical GPU output. The common player/sidekick projectile draw function is exercised, not a claim that those producers were naturally reached. Existing generation, geometry, gameplay and render eligibility are unchanged.

The original data is verified and sent to the harness over stdin by the historical driver; no original game bytes are part of these test artifacts. Renderer and relevant modified translation units use ASan+UBSan; unchanged optimized baseline native objects are reused after source equality checks. This is not a claim that every linked object was sanitizer-instrumented.
