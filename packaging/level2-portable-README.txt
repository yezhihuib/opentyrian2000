OpenTyrian 第二关 HD 自由试玩（Windows x64）

开始试玩
1. 先核对 ZIP 的来源和 SHA256，再完整解压到本地磁盘上新建的空文件夹。
   该文件夹必须可写，并位于原版 Tyrian 2000 数据文件夹之外；两者不能互相包含。
   不要覆盖或合并到已有目录，不要使用网络共享或映射的网络盘，也不要在 ZIP 预览窗口中运行。
2. 双击 Start-Level2-Preview.exe。
3. 在弹出的选择窗口中，选择你已有的 Tyrian 2000 原版数据文件夹。
   请选择直接包含 tyrian.hdt、tyrian.shp 等文件的那一层，而不是它的上层。
4. 启动器会核验文件，然后进入 ASTEROID2 单关自由试玩。默认 4 倍显示。

不需要安装 Python 或 PowerShell。bin 文件夹里的 exe 由启动器调用，请不要直接运行。
若 4 倍窗口太大，双击 Start-2x.cmd 即可以 2 倍显示启动同一个原生启动器。
不要更改兼容性、安全软件或系统安全设置。此预览未签名；若系统阻止运行，先停止并核对来源。
启动器只选择并复制清单列出的文件，但 Windows 会在启动器开始核验前加载其系统依赖。
因此请保留原始包内容，不要往解压目录加入其它 DLL；核对 ZIP 和使用全新空目录仍然必要。

操作
方向键：移动；空格：开火；Enter：切换后方武器模式；Esc：菜单／退出。
这是正常手动操作的单关试玩，没有录像回放、脚本输入、asset-debug 或 game-probe 启动参数。
开场的原生短暂无敌效果可能仍显示经典画面。未支持的对象、特效或状态也会保留经典画面。
HUD 只启用已批准的静态边框；动态文字和仪表仍由原生逻辑绘制。
本包不代表整关 HD 已完成，也没有宣称通过原生 Windows、物理 GPU、音频或真实键盘验收。

原版数据与个人文件
本 ZIP 不包含原版游戏数据。启动器只接受指定版本的已核验原版数据文件。
每次启动都会创建新的 sessions 子文件夹，仅把明确列出的原版资源复制到该次会话的 data 中。
不会复制原版目录里的配置、存档、程序或其它额外文件，也不会修改你的原版目录。
每次会话的配置、诊断日志和运行数据保存在自己的 sessions 子目录，不会复用你的已有存档。
请不要公开分享 sessions 文件夹，它包含你自己的原版数据副本和日志。
若选择了不匹配的数据版本，启动器会停止并说明缺失或不匹配的文件，不会自动下载替换文件。

原版数据来源信息：https://www.camanis.net/tyrian/tyrian2000.zip
此链接仅供核对来源；包内程序不会下载它。数据的文件名、大小和 SHA256 见
metadata/ORIGINAL-DATA-HASHES.json，里面没有原版资源内容。

核验与复现
包标识：@BUNDLE_ID@
冻结源码：@SOURCE_COMMIT@
metadata/PACKAGE.json 列出包内文件的大小和 SHA256（清单本身除外）。
metadata/BUILD-MINGW.json 与 LAUNCHER-BUILD.json 记录引擎及启动器的构建身份。
source/ 包含对应源码、生成的启动器清单和构建脚本；复现说明见 source/docs/LEVEL2_PORTABLE.md。
开源许可和依赖通知见 licenses/。OpenTyrian 为 GPL-2.0-or-later；SDL2/SDL2_net 为 zlib 许可。
包内没有原版游戏数据、用户配置／存档／日志、私有 redvent 或未经批准的边缘裁剪资源。
