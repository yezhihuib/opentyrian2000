# Built-in imagegen prompt set

Reference images were decoded original157/159/161 sprites enlarged by nearest-neighbor solely as geometry references. Masters are project-bound generated images; no CLI/API fallback was used. The initial open-pose output was rejected as pixelated, then edited as follows. The accepted open master supplied identity/style for each separate pose call.

## Deterministic registration

The compiler does not repaint any generated surface. It crops each accepted master's alpha>128 bounding box, resamples into the matching original per-pose logical bounding box at8×, then zeros RGBA outside the exact original coverage. See provenance.json and art-inventory.json for hashes and crop coordinates.
