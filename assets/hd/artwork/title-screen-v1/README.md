# Title screen art v1: frozen offline source

Three generated-only canonical assets, reviewed on 2026-10-12. PIC4 is an opaque 1280×800 RGBA card. Tyrian PLANET146 is a separate 1216×484 straight-alpha logo. The 2000™ PLANET151 sprite is a separate 648×256 straight-alpha logo. Full logical canvases are 320×200, 304×121 and 162×64 respectively. All files use top-left registration and square logical pixels.

## Rebuild

Use Python 3 with Pillow 12.3.0, then run `python3 build.py --output /absolute/new/external/output`. The output parent must already exist. The builder refuses relative paths, existing outputs, symlinked output paths and paths inside or above this package. It verifies all five source master identities and canonical output hashes. It does not read the canonical PNGs or any game data as build inputs. Imagegen prompts document provenance; reproduction starts from the immutable generated masters rather than claiming stochastic image generation is repeatable.

The three canonical PNGs plus `expected-hashes.json` are the exact integration inputs. Decode to row-major straight RGBA without quantization, recoloring, palette conversion or a second resampling pass. All RGB channels at alpha 0 are zero. Partial-alpha RGB and coverage are retained. PIC4 alpha is 255 everywhere. Native 2× is nearest sampling of the canonical 4× image, matching the reviewed pilot. The canonical PNG encoder may differ across Pillow versions; raw RGBA hashes are independently pinned.

## Registration and correction

PIC4 uses a full-canvas resize. Each logo master’s visible alpha (>16/255) bounds are fitted into the audited source opacity bounding box at 4×, inside its unchanged full sprite canvas. Those fixed bounds are Tyrian [4,4,1216,484) and 2000™ [8,8,644,252). The original low-resolution mask is not imposed on the generated contours.

The approved Tyrian correction uses alpha only from two generated component masters. The builder resizes them to their original registered crop rectangles and applies minimum coverage within three exact logical corridors: [90,46,96,58), [200,61,207,67), [210,63,215,77). Exactly 1,498 canonical alpha samples change. No other alpha or retained visible RGB changes. The original single meaningful Tyrian counter remains; three accidentally closed channels are open at canonical 4× and native 2×. The 2000™ logo retains its three counters. Fully transparent hidden RGB is normalized to zero after compositing. The boundary mask and numerical proof are included.

## Sequence and runtime boundary

Keep PIC4, Tyrian and 2000™ separate. Initial positions are (11,62)/(155,41). For i=0..28, positions are (11,60−2i)/(155,45+i). Settled/restart positions are (11,4)/(155,73). Draw Tyrian before 2000™. All 29 offline positions are validated and hashed at canonical 4× and native 2×. Initial, middle and settled 2×/4× art-only previews can be regenerated by the builder; they contain no baked menu, version or cursor.

Original title behavior remains a runtime contract: art indices 0..239 use the 10-step fade, UI indices 240..255 use the later 20-step fade. Original live version/shadow, menu selection and cursor need their exact ordered composition above or between the art stages. Both logos cross the menu rows, so a blanket rectangular menu cutout is invalid. Preserve original timing, input, restart/demo return and classic fallback. The exact source compatibility IDs, hashes and role metadata are in source-compatibility.json.
