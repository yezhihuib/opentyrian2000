# Generated terrain completion masters

Seven frozen image-generated RGB masters plus original generation prompts.
These are candidate redraws, not original game textures. Each master's SHA-256,
size and slicing layout is pinned by `scripts/build_level2_terrain_completion.py`.

The five pit/column/shaft masters depict coherent assemblies. `fixtures.png`
and `architecture.png` are regular 4x2 contact sheets of independent reusable
tiles; do not interpret those sheets as actual map layouts. Cutting and alpha
application are deterministic build operations, not additional image generation.

Private composition/style references mentioned in prompts are intentionally not
bundled. No raw original reference images or maps should be added here.

See `docs/level2-family/TERRAIN-COMPLETION-CANDIDATE.md` for reproduction,
actual-image review, provenance and unqualified material/scene transitions.
