# Rear Multi-Cannon P7 mode2 twin streaks

Generated-only heads294/295 preserve the12x14 logical canvas and anchor(0,0).
Two new semantic9x10 cubic cap/taper streaks are offset(+3,+3), perpendicular
to down-left travel. The original twin topology and down-diagonal direction
are preserved without tracing original indexed boundaries or masks.

The seven yellow/orange/red gradient stops match the accepted front Multi
style. There is no casing, outline, gray border, blur, external halo, native1x
intermediate, or claim of original pixel coverage/energy equality. The
one-logical-pixel top margin remains empty; logical support is[0,1,12,14].

Canonical294 is rendered independently from SVG at densities4 and8.
Canonical295 is the exact full-canvas horizontal RGBA reflection at each
density. The standalone295 SVG is an explanatory source comparison, not its
canonical payload. Its rasterizer edge variation is measured separately in
output/build-receipt.json: max alpha17/255, synthetic-brown composited RGB
max delta7(d4)/8(d8). No native brightness compensation is applied.

All four resources include byte-equivalent straight RGBA, PNG and HDR1,
role131 keys1310294/1310295, with exact EOF and zero RGB at zero alpha.
Existing277/278/77 and every other pre-existing asset remain unchanged.
Admission is limited to ordinary player1 rear10/bay1, power index6, mode
index1, exact normal-table record271 with phases277,278,295,294,77.
Physical alias1271, later powers, alternate data, generic/shared/linked
consumers and indexed shadows are excluded.

## Rebuild

Use the Node/Sharp renderer versions pinned in pins.json, then run:

    node build.cjs /absolute/new-output-directory

The destination must be fresh. The builder reads only authored SVG, code,
contract and pins; it has no repository, game data, palette, mask, capture or
reference-raster dependency. Source/input/renderer/output mismatches fail
closed. To reproduce the authoring sources separately:

    node author-geometry.cjs /absolute/new-source-directory

The compact public package excludes synthetic preview sheets and copied
accepted reference rasters. Historical validation and relocated-rebuild
receipts record the offline checks; public asset tests independently repeat
payload/header/reflection, native two-component and source-only rebuild
checks. file-manifest.json is the complete public package whitelist.
