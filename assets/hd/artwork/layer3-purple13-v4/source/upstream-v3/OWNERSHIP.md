# Generated-art source ownership and distribution boundary

This is an authored-source handoff for the user's OpenTyrian HD-art project. The
13 opaque terrain source crops and the small actor-edge reference are project
AI-generated artwork. The actor-edge reference is supplied by the companion
purple-installation artwork task for the same project; its six crop origins and
source hashes are explicitly recorded. The selected terrain outputs are derived
only from these included generated sources by the included finite tone-registration
helper. The newly supplied packaging and verification scripts are project tooling.

The supplied prompts describe the original authoring intent, including the use of
private visual references. Those reference images are not included. Source IDs,
slots, geometry, bounded topology facts and hashes are compatibility/provenance
metadata. They are not bundled original game art, masks, palette samples or map
arrays. No original game raster, game data file, full generated master, screenshot,
video, prebuilt executable or archive is distributed in this package.

This document attributes the project sources. It does not determine the legal
copyrightability of AI output, grant rights to third-party game assets, or replace
any license governing the destination project. No additional open-source license
for the artwork is asserted here. Keep the project's existing licensing and
attribution decisions when integrating this handoff.
