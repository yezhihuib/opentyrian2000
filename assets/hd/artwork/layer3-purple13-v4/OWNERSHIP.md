# Generated-art source ownership and distribution boundary

This is an authored-source handoff for the user's OpenTyrian HD-art project.
The 13 terrain source crops, small v3 actor-edge tone reference, and three new
terrain fringe strips are project AI-generated artwork. The selected terrain
outputs derive only from those included generated sources using the included
canonical finite C++ helpers. Rebuild and validation scripts are project tooling.

The new strips are the terrain-only portion of coordinated project-generated
fringe authoring. Companion actor strips and frames are excluded. Prior source
ownership and crop provenance are preserved; new strip provenance records exact
registered crop identity and explicitly excludes the private full master.
Prompts record authoring intent, including private visual references, but those
reference images are not distributed.

IDs, slots, geometry, bounded topology facts, and hashes are compatibility and
provenance metadata. The package contains no original game artwork, masks,
palette samples, game data/map arrays, full generated masters, runtime captures,
prebuilt/private executables, or archives.

This document attributes project sources. It does not decide the copyrightability
of AI output, grant rights to third-party game assets, or replace the license of
the destination project. No additional artwork license is asserted. Preserve the
project's existing licensing and attribution decisions during integration.
