# Title menu medium font V3.1

Frozen genuine-cubic vector geometry plus font-only native2× ordered coverage integration approved from offline normal and selected comparisons. This package supplies the medium/table1 font only. It does not activate settings, load rows, large headings, other font banks, or any global replacement. Nine original blank slots remain blank. All original widths, heights, advances, ascender/descender registration, caller palette arithmetic and ordered title outlines remain authoritative.

## Rebuild

Use Python 3 and Pillow 12.3.0. Run `python3 rebuild.py --output /absolute/new/external/directory`. Output must not exist, be inside or above this source directory, or traverse a symlink. The builder reads only sources/menu-normal-vectors.json and contract.json; neither game data nor canonical files are inputs. It checks every glyph's coverage and role hashes and every output hash. The SVG is editable geometry; the numerical Pillow rasterizer defines canonical texels.

## Runtime binding

The optional TMF1 payload is 128 header bytes, 344064 coverage bytes, then 344064 shade-role bytes. All 85 slots retain source registration. Only 76 slots have ink; nine legitimate blank ASCII glyphs advance normally without ink. Unsupported or missing glyph runs must stay wholly classic. Main title uses original four diagonal COLOR outlines at brightness -10, normal -3, selected -1, hue15 and live palette8. Apply tilde+4 and original clamp exactly; palette index255 is legitimately red. Do not substitute black outlines or setup's destination-darkening shadow. Preserve row and whole-string draw order, menu base/highlight checkpoints, cursor, fades and classic fallback.

## Provenance and scope

The independently authored cubic centerlines reconstruct curved bowls, shoulders, the source medium M/W arches and asymmetric V at1.90 logical stroke. No original reference RGB, indices, palette tables, encoded sprites or comparison screenshots are included. Technical source hashes and metrics are retained for compatibility, with portable source names. Canonical files exactly match the approved V3 pilot atlas. V1 thin and V2 chamfered variants remain separate superseded drafts outside this package.

The native2×/4× preview was an offline composition on approved title art. Its original version footer came from an existing2× retained still and was replicated for the4× comparison; only medium menu text was authored. No new game capture or runtime acceptance is claimed. Actual renderer sampling, menu overlap/order, selection changes, palette fades, cursor/restart and coherent unsupported-run fallback are later engineering and author gates.

## Font-only native2× integration

The resource stays canonical4×. For each2×2 canonical font group, repeat the same nearest title-underlay RGB under its four samples, replay every original ordered outline/base/highlight command with live palette-role RGB and integer source-over, then compute(sumRGB+2)//4. This preserves overlapping pass order and averages neither palette indices nor artwork. Reducing each pass before composition is rejected: the retained witness differs by46 channel levels. Native4× remains exactly the ordinary canonical rendering. Other output sizes are not approved by this pilot. The compact sampling proof is separate from runtime acceptance.
