## Registered retained art

Both original sprites occupy 45 logical cells in a12×14 tile. Retained96×112 source PNGs are byte-verified copies of existing authored default-pack artwork. The historical master atlas is not available; this is not a claim of new image generation or regeneration from that master. The deterministic compiler zeros RGBA outside the exact original support and preserves authored RGB **and alpha** inside. Every source cell remains represented. Partial alpha preserves the soft warm rim; an opaque-alpha trial was rejected for introducing a black cutout. Original coordinates and zero anchor are retained. Default artwork and catalog entries are unchanged.

The two optional files are one atomic family. Missing/corrupt either member disables both while other families remain independent. Private leases prevent generic or cross-family admission. Cached resource metadata and RGBA are authenticated once per logic tick; live original source bytes are authenticated every callback. This does not claim detection of arbitrary cached-RGBA mutation later within the same tick. Disk replacements require renderer cache shutdown/new root epoch.
