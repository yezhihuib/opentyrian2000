Compositing
Original indexed replay supplies the destination-index operation
H(i)=(i&240)|((i&15)/2). Authored coverage and discrete roles12–15 generate a
transparent premultiplied ARGB layer at canonical1280×800. Ordered shadows and
faces are composed at correlated canonical samples before output integration;
role indices are never interpolated. Authored gaps remain transparent. The
indexed pre-font PIC2 plus original cursor is separately passed through the
exact currently selected software scaler and reference-texture sampling mode.
No complete RGB scene is reduced to manufacture font antialiasing.

For each output pixel, integrate only the ordered premultiplied font layer across
its canonical footprint on reducing axes; magnified axes use nearest coverage.
Composite that result over the exact selected-scaler underlay pixel. This makes
background pixels outside original/authored glyph influence exactly unchanged.
The fixed8-bit premultiplication arithmetic is explicit and independently tested;
it is not claimed bit-identical to previous full-scene Settings/Load compositors
at fractional alpha. Fully opaque ink and alpha gaps retain exact semantics.

Coordinates derive from actual renderer output, destination, renderer scale and
physical viewport/clip, matching SDL's software-renderer destination rounding.
The original window-coordinate destination and inverse input mapping are never
corrected or rescaled. Thus renderer/window mismatch follows the same baseline
frame geometry rather than guessing a DPI multiplier. Signed clipping handles
negative and partial destinations; no640/1280 or monitor-name admission list.
Original title/Settings/Load geometry restrictions remain separately qualified.

Cursor correctness boundary
The ordinary cursor keeps its chosen scaler. A conservative cursor/filter source
dependency rectangle is locally restored from the exact original classic output;
this retains original text beneath the pointer and avoids nearest-repainted
cursor edges, missing-text halos and whole-frame typography flicker. HD typography
inside that small cursor neighbourhood is deliberately not promised. The output
module tests exact classic pixels there. The source cursor write bounding box is
expanded by the selected scaler dependency radius (nearest0, Scale/HQ1), plus
one original pixel when reference sampling is non-nearest. It is mapped outward
to output pixels and clipped to the affected font region/viewport/output. Those
exact classic output pixels are saved in reusable streaming128×64 tiles and
restored1:1 last; this is a correctness fallback,
not new cursor artwork or a separate cursor/filter compositor.
