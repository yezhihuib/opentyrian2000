# ASTEROID1 large and small static random rocks

This checkpoint adds two imagegen-authored, source-aligned static designs to the
separate normal-data Episode1 physical-level1 ASTEROID1 opt-in:

- bankD/base123: one24×28 image, shared by records266,267,268 (downward speeds4,5,6)
- bankD/base95: one12×14 image, shared by records317,318 (downward speeds2,4)

These are motion variants, not animation frames. Their complete original source
sequences each contain one pose, with no turret, launch or damaged-image state.
The original random table also has the separately animated record286; it is not
covered here. The cool slate-grey original95 and neutral grey123 color relationship
is retained with continuous painted stone surfaces and natural contours. The
master PNGs and exact prompts are under the corresponding artwork directories.
Only source-bound global alignment and inward coverage are applied by
prototype/build-asteroid1-random-static-art.py. No original data or captures are
packaged in this repository.

## Presentation-only scope

Use the existing --asteroid-hd-assets flag with the optional asteroid1-ten-v1
pack. It now has26 images,33 source records and nine independently preflighted
families. Both default gameplay packs remain629 files each, byte-for-byte unchanged.
All24 previously accepted optional HDAs are unchanged.

Both families independently verify loaded enemy-bankD identity and exact current
42012 source bytes, every77-byte sibling record, resource role108/density8,
geometry, anchor, exact length and RGBA pin. Size0 uses one unquadranted original
call; size1 preserves ordered0/1/19/20 calls. Private caches are independently
preflighted and sticky per selected root. Warm dependency failure after accepted
drawing rejects that display frame; cold failure retains local classic fallback.
Physical levels other than1, other episodes, multiplayer, demo, bonus and excluded
modes remain out of scope. Gameplay, random tables, RNG, movement, collision,
indexed drawing, destruction and event data are unchanged.
