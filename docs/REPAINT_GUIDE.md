# 高清重绘简明规则

保持原游戏逻辑坐标、碰撞、随机数、关卡与视野，仅替换独立高清渲染。以下规则用于制作与验收，不记录每轮过程。

1. **真实小图优先。** 源图精细不代表游戏里清楚。先按实际显示尺寸检查轮廓、识别特征和明暗大面，UI 也按真实界面大小看。记录逻辑、源图、绘制与窗口尺寸，别把测试窗口当最终画质。
2. **重建形体。** 像素阶梯、抖色和方块高光是低分辨率表达，不直接做成立体结构。重建连续曲率和高光，保留真实硬边，不靠全局模糊或腐蚀修边。
3. **材质清楚。** 机械用统一光源、倒角、厚度和受控反射表达金属；蓝红涂装也不能像塑料。缩小后过密的刻线要减，碎高光要合并。岩石与能量保留自己的材料特征。
4. **多视图共用刚体。** 先看齐全部原帧，再用同一个 3D 或 2.5D 模型输出角度。核对连接点、厚度和中间角度遮挡，避免逐帧重画导致机头、机翼弯曲。旋转或多角度怪物可建模后渲染成协调的2D风格；普通平面怪物直接重绘替换素材，不建模；素材制作由dot云端负责，Codex只做代码与接入。
5. **按结构对齐。** 绘制 anchor、结构轴和视觉中心分别记录。组件在同一坐标系中按连接点对齐，不按各自包围盒独立居中。
6. **隐藏部分画完整。** 保留独立对象的 ID、健康与破坏状态、覆盖顺序。不得把遮挡烘焙成缺口或合成不可拆运行资源；对照预览可以合成。必测组件消失、破坏和缺素材。
7. **地形看真实邻接。** 先查 ID、偏移和 alpha，再检查局部及全景的新旧边界。局部无缝不代表全图通过。必要时处理整套边缘家族，不擅改已验收邻居掩盖接缝。
8. **分层诊断采样。** 区分源图、离线缩小、查看器二次缩放和游戏实际渲染。先找成因，每轮只改一个变量；离线滤波不能冒充游戏结果，试验只影响高清路径。
9. **连续检查所有状态。** 覆盖正常、倾斜、透明、复活、受击、闪烁、护盾、爆炸、调色板、淡入淡出、缺图、暂停及重复呈现。从转换前看到结束后稳定帧，逻辑测试或抽帧通过不能代替视觉验证。
10. **防止旧图回退。** 按资源表和运行数据核对完整动画区间，特别检查尾帧。回退矩形不得污染已高清化对象。保留可再生成的模型、贴图、脚本、映射与必要回退；只记录实际验证到的范围。

## 最短验收清单

- [ ] 真实尺寸下造型、材质、角度、轴线与组合正确
- [ ] 全状态连续检查，无缺帧、旧图回退或邻接接缝
- [ ] 逻辑、classic 与 UI 未受影响，未验证项明确
- [ ] 候选、视觉认可、已接入、完整验证分开记录
