OPTIONAL STARTUP, TITLE, SETTINGS AND LOAD TYPOGRAPHY

Use the existing nine-file pack, without copying or replacing resources:
  opentyrian2000 --startup-assets assets/hd/packs/startup-title-settings-v1
Supply original Tyrian data through the normal data-directory selection.
The existing selector is --startup-assets. There is no new Load-specific CLI flag.

This candidate adds Load compatibility with the same frozen SFN1 large and tiny
resources already in that pack. Settings still uses its existing large, medium
and tiny resources. Startup and title resources, all previous packs, manifests,
artwork, registration and font metrics remain byte-exact. No duplicate combined
pack or new art bytes are introduced. The original no-pack path remains classic.

Load is a dedicated, bounded owner with exact original heading/row/footer
geometry. Accepted native outputs are nearest 2x (640x400) and nearest 4x
(1280x800). Unsupported fields, bytes, markup, source data, scaling, invalid or
missing required resources, or an unsafe lifetime transition retain the whole
classic frame. The supported second page can reacquire after a bad-name first
page. A 2x scaler in a resized 1280x800 window intentionally remains classic.

The nine-file compatibility is established by unchanged resource identities,
source/owner isolation, aggregate package checks and prior startup/title/settings
acceptance. The actual Load A/B matrix isolated the identical large/tiny resources
so other owners remained classic. It does not claim a new actual combined-pack
startup/title/Setup run. Existing settings source and title synthetic production
regressions are rerun separately.
