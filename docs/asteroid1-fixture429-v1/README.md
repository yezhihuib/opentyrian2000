## Admission and validation

Private terrain material144 is separate from enemy-body leases and generic201 admission. The family must authenticate its original source identity, layer1 map and row provenance, supported layout and context; all four resources must validate before replacement. Unknown contexts and failed resources retain classic output. The complete4,200-cell original map identity and all registered duplicate target-source bytes are rechecked for each active row. Real loader-slot identities reject aliases and copied source pointers. Resource metadata is checked on every callback, while cached RGBA payload integrity is checked once per logic tick. Arbitrary same-tick payload mutation detection is therefore not promised; a changed cached payload is rejected on the next tick. Disk replacement requires shutdown/new resource epoch. A fully authenticated visible-window scan bypasses resource loading when none of the four targets is present. Final evidence is recorded in validation.json after acceptance.

Portable art checks rebuild the unified split and validate source support, dimensions, roles, source PNG and payload pins. Native paired2×/4× scrolling tests must cover all five placements, internal seams, viewport clipping, foreground overlap, unchanged indexed/state/RNG/star traces, and missing/corrupt/off controls before acceptance. Assisted SDL software windows are not natural whole-campaign or desktop certification. ASan/UBSan runs with LeakSanitizer disabled are not a full leak proof.
